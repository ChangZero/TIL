# Vue 공부 내용 정리

## Vue를 사용하는 이유
- 자바스크립트 Dom을 사용
- 동적 데이터 처리 수월
- 컴포넌트 기반으로 UI 요소들을 모듈화 진행
- Vue에서 제공하는 디렉티브들도 조건문이나 반복문 등을 쉽게 구현 가능
- 가볍고 성능 좋음

Vue 셋업
```shell
npm install -g @vue/cli
```

```shell
vue create movie-info
```

실행할 경우
```shell
npm run serve
```
## Vue 구조 살펴보기

template에는 HTML 코드가 작성됨
script에는 자바스크립트 코드가 들어감
style에는 CSS 코드가 작성됨
